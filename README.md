Entry for [Monday, Reviewed in One Line](https://make.fun/c/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) on make.fun — the funniest one-line review of my own Monday, under 200 characters.

## How it works

`main.ts` (Node 22, standard library only) writes a single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It gates the line: it must be 1–200 characters and not only whitespace, or the program fails. The output is deterministic — the same line every run.

## The line

> Monday, reviewed: the 9 a.m. standup lasted an hour, nobody stood up, and my inbox turned my lunch break into a meeting about lunch.
